# PLC 구조화 프로그래밍의 내용
이 책은 산업용 자동화 제어에 필수적인 IEC 61131-3 표준 기반의 PLC 프로그램(미쓰비시 Q시리즈 PLC 기준)을 기초부터 실무 응용까지 다루는 실용서입니다.

### 1장 IEC 61131 개요
IEC 61131 표준의 역사적 배경과 구조적 특징을 다루며, 구조화 프로그래밍의 필요성을 이해하는 발판을 마련합니다.
### 2장 따라하기
실무 감각을 익히기 위한 샘플 프로그램입니다. 조작 방법을 숙달시키고 실전에서 어떻게 사용되는지를 파악하기 위한 구성입니다. 초보자에게는 다소 어려울 수 있으므로 내용보다는 개발 환경을 이해하고 뒷장의 이론 학습 후 재학습을 권장합니다.
### 3장 구조화 프로그램
구조화 프로그래밍의 공통 사항과 Q시리즈 PLC에 특화된 데이터 구조와 특성을 분석하여 탄탄한 기본기를 다집니다.
### 4장 Structured Ladder/FBD
기존 심플 프로젝트 방식과의 차이점을 설명합니다. FB(Function Block)와 FUN(Function)을 혼용하여 프로그램의 생산성을 극대화하는 방법을 배웁니다.
### 5장 Structured Text
텍스트 기반 제어 언어인 ST(Structured Text)의 구조를 배웁니다. 복잡한 연산이나 데이터 처리를 효율적으로 제어하는 방법을 습득합니다.
### 6장 Library 
표준 함수 및 Q 시리즈 PLC 함수를 설명합니다. 매뉴얼의 한계를 넘어선 풍부한 현장 실무 예제와 인텔리전트 모듈의 필수 정보가 수록되어 있습니다. 사용자 라이브러리 함수가 어떻게 작성되고 사용되는가를 이해하도록 응용 함수와 내부 함수를 재구현합니다. 예제는 HMI와 연동하여 내부 상태를 쉽게 파악할 수 있도록 합니다.
